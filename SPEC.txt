thiết lập cho chạy chuỗi dự án:
$[Tên folder1] // tên sẽ dùng cho việc tạo tên folder outputs
    [Text 1] Detail Text 1
    [Text 2] Detail Text 2
    ...
    [Text N] Detail Text N
    Vd:  Tên folder 1 là:  An toàn_nghiệp_vụ, Text 1 là [Text 1] là [An toàn_nghiệp_vụ-1]...
Tên folder có thể bao gồm dấu gạch dưới "_" , số và chữ

Kết quả
    Outputs
        [Tên folder1]
            Các file output liên quan
        [Tên folder2]....

Đầu vào có thể là 1 file text: lấy tên folder chính là tên txt
Có thể là 1 file docx: Có nội dung phân phối như trên

Có thể thực hiện ngay trên UI, hoặc ngay trên Colab với các lựa chọn là giọng áp dụng, chế độ mặc định là cân bằng tự nhiên
